### **主成分分析（PCA）简介**
PCA（Principal Component Analysis，主成分分析）是一种**降维**方法，常用于：
- 识别数据的主要变异来源
- 进行可视化（特别是高维数据）
- 发现数据结构（如群体结构、生物变异）

在**基因组学和生物信息学**中，PCA常用于：
- **种群结构分析**（比如GWAS研究）
- **基因表达数据降维**（RNA-seq）
- **结构变异（SV）的模式探索**（如你的研究）

---

### **PCA 分析流程**
#### **1. 数据准备**
PCA 需要一个**数值矩阵**，比如：
- **基因型数据**（SNP矩阵, SV矩阵）
- **基因表达数据**（RNA-seq TPM, FPKM, RPKM）
- **表型数据**（如生长性状）

通常，数据格式如下（行是样本，列是变量）：
| Sample | Feature1 | Feature2 | Feature3 | Feature4 | ... |
|---------|----------|----------|----------|----------|-----|
| A       | 1.2      | 3.4      | 2.1      | 4.5      | ... |
| B       | 2.3      | 4.1      | 3.2      | 5.2      | ... |
| C       | 1.5      | 3.7      | 2.4      | 4.8      | ... |

**基因组学数据的PCA：**
- SNP数据：通常用 `plink` 进行 PCA
- 结构变异（SV）数据：可以用 `R` 或 `Python` 处理

---

#### **2. 标准化数据**
PCA 需要**中心化和标准化数据**（均值0，标准差1），否则不同量纲的数据会影响结果。  
标准化方法：
- **Z-score** 标准化：
  \[
  X' = \frac{X - \text{mean}(X)}{\text{std}(X)}
  \]
- **SNP 数据标准化**：
  - `plink` 自带标准化
  - 可以用 **PCAcov** 方法去除 LD 影响

---

#### **3. 计算主成分**
PCA 通过特征值分解（Eigendecomposition）或奇异值分解（SVD）来计算主成分：
- 传统PCA：**特征值分解**
- 高维数据（如基因组数据）：**SVD更稳定**

PCA 计算：
- 计算协方差矩阵
- 进行特征值分解
- 选取前 `k` 个主成分

在 Python 中：
```python
from sklearn.decomposition import PCA
import numpy as np

# 假设 X 是样本 x 特征的矩阵
X = np.random.rand(100, 50)  # 100 个样本，50 个特征

# 标准化
from sklearn.preprocessing import StandardScaler
X_std = StandardScaler().fit_transform(X)

# 计算 PCA
pca = PCA(n_components=2)
principal_components = pca.fit_transform(X_std)

# 解释方差
print("解释方差比:", pca.explained_variance_ratio_)
```

---

#### **4. 解释 PCA 结果**
**常见输出：**
1. **主成分得分（PC1, PC2）**
   - 说明每个样本在 PCA 轴上的位置
   - 用于 **绘图（PCA可视化）**
2. **特征贡献（Loadings）**
   - 说明哪些变量对 PCA 贡献最大
   - 重要用于**基因组研究**，可以查看哪些 **SNPs 或 SVs 主要影响 PCA 变异**
3. **解释方差（Explained variance）**
   - 说明前几个主成分解释了数据多少变异

**PCA 绘图**
```python
import matplotlib.pyplot as plt

plt.scatter(principal_components[:, 0], principal_components[:, 1])
plt.xlabel("PC1 (%.2f%%)" % (pca.explained_variance_ratio_[0] * 100))
plt.ylabel("PC2 (%.2f%%)" % (pca.explained_variance_ratio_[1] * 100))
plt.title("PCA 分析")
plt.show()
```

### **在基因组数据中的应用**
#### **1. SNP PCA**
- 使用 `plink` 计算：
  ```bash
  plink --bfile data --pca 10 --out pca_results
  ```
- 输出：
  ```
  pca_results.eigenvec  # PCA坐标
  pca_results.eigenval  # 解释方差
  ```
- PCA 绘图：
  ```R
  library(ggplot2)
  pca <- read.table("pca_results.eigenvec", header=F)
  ggplot(pca, aes(V2, V3)) + geom_point() + theme_minimal()
  ```

#### **2. 结构变异（SV）PCA**
如果你要对**结构变异（SV）进行 PCA**：
- 需要构建一个 SV 矩阵（行 = 样本，列 = SV 存在/缺失）
- 进行 `PCA` 计算
- 分析不同鱼群之间的变异性

### **使用 `plink2` 将 VCF 文件转换为 BFILE 格式（bed/bim/fam）**

在 **PLINK2** 中，可以使用以下命令将 **VCF** 文件转换为 **BFILE**（`bed`, `bim`, `fam`）格式：

---

## **💡 方法**
### **1. 直接转换 VCF 到 BFILE**
```bash
plink2 --vcf input.vcf.gz --make-bed --out output
```
📌 **参数解析：**
- `--vcf input.vcf.gz`：输入 **VCF 文件**（支持 `.vcf` 和 `.vcf.gz`）。
- `--make-bed`：将 VCF 转换为 **BFILE 格式**（`bed`, `bim`, `fam`）。
- `--out output`：输出文件前缀（生成 `output.bed`, `output.bim`, `output.fam`）。

---

### **2. 处理含有样本表型信息的 VCF**
如果你的 VCF 文件包含 **表型信息（phenotype）**，你可以使用 `--pheno` 参数：
```bash
plink2 --vcf input.vcf.gz --make-bed --pheno phenotype.txt --out output
```
其中 `phenotype.txt` 需要是 **样本ID + 表型** 的格式：
```
FID IID PHENO
sample1 sample1 1
sample2 sample2 0
sample3 sample3 2
```

---

### **3. 过滤低质量 SNPs**
如果你的 VCF 数据很大，建议先 **过滤低质量 SNPs**：
```bash
plink2 --vcf input.vcf.gz --maf 0.05 --geno 0.1 --hwe 1e-6 --make-bed --out output
```
📌 **过滤参数解释：**
- `--maf 0.05`：**最小等位基因频率（MAF） ≥ 5%**（去除罕见变异）。
- `--geno 0.1`：**去除缺失率超过 10% 的 SNPs**。
- `--hwe 1e-6`：**Hardy-Weinberg 平衡筛选**（去除违反 HWE 的 SNPs）。

---

### **4. 指定样本列表进行转换**
如果你只想转换部分样本：
```bash
plink2 --vcf input.vcf.gz --keep sample_list.txt --make-bed --out output
```
📌 **`sample_list.txt` 格式：**
```
FID IID
sample1 sample1
sample2 sample2
sample3 sample3
```

---

### **5. 结果文件**
执行 `plink2` 后，最终会得到：
- `output.bed`：**二进制 SNP 数据**
- `output.bim`：**SNP 注释信息**
- `output.fam`：**个体信息（家系ID、个体ID、性别、表型等）**
