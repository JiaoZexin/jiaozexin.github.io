Cicer super-pangenome provides insights into species evolution and agronomic trait loci for crop improvement in chickpea [NG 2024](https://doi.org/10.1038/s41588-024-01760-4)


The publication uses the following tools and software:

1. **Raspberry v0.2** – A tool used for genome assembly or analysis.
2. **DeNovoMAGIC 2.0** – A genome assembly pipeline specifically designed for de novo genome assembly.
3. **Juicebox v1.13.01** – A visualization tool for Hi-C genomic interaction maps.
4. **3D-DNA** – A software pipeline for genome assembly and scaffolding using Hi-C data.
5. **RepeatMasker v4.1.0** – Identifies and masks repetitive DNA sequences in genomic data.
6. **RepeatProteinMasker v4.1.0** – Used for masking repetitive elements based on protein sequences.
7. **RepeatModeler v1.0.11** – A tool for de novo identification and modeling of repetitive elements.
8. **ltr_finder v1.0.6** – Detects long terminal repeat (LTR) retrotransposons in genome sequences.
9. **ltr_retriever 2.9** – A tool for identifying and curating LTR retrotransposons.

These tools were used in the study for genome assembly, structural annotation, and repeat element identification.

This publication utilized several bioinformatics tools and software, including:

1. **PseudoPipe** - An automated pipeline for identifying pseudogenes in genomic sequences.
2. **RGAugury** - A pipeline for genome-wide prediction of resistance gene analogs (RGAs) in plants.
3. **Circos** - A visualization tool for comparative genomics, particularly useful for displaying genome structure relationships.
4. **GENESPACE** - A tool for tracking genomic regions of interest and analyzing gene copy number variations across multiple genomes.
5. **OrthoFinder** - A tool for inferring orthologous relationships across species for comparative genomics.
6. **PAML (Phylogenetic Analysis by Maximum Likelihood)** - A software package for phylogenetic analysis based on maximum likelihood methods.
7. **SnpEff** - A program for annotating and predicting the effects of single nucleotide polymorphisms (SNPs) in genomic studies.
8. **Minimap2** - A fast sequence alignment program used for mapping long reads.
9. **plotsr** - A visualization tool for structural variations and genome rearrangements across multiple genomes.

These tools were employed to analyze structural variations, comparative genomics, and functional annotation of genes.
